🇫🇷 Анти-ИИ Квен Академия | Полный тренажёр ЕГЭ-2026 по французскому языку
English: Anti-AI Qwen Academy | Full French EGE-2026 Trainer
Бесплатный, автономный HTML-тренажёр для подготовки к ЕГЭ по французскому языку 2026 года. Работает без интернета, без регистрации и без рекламы. Поддерживает переключение интерфейса между русским (RU) и английским (EN) языками.
✨ Особенности проекта
🎧 Полная поддержка Аудио:
Интеграция с официальными файлами audio-fr.mp3 (письменная часть, задания 1–9) и audio-fr-oral.mp3 (устная часть, задание 3).
Если аудиофайлы отсутствуют, автоматически включается резервная учебная озвучка через встроенный синтезатор речи браузера (Web Speech API), чтобы вы могли тренироваться даже офлайн.
🗣️ Устная часть (Speaking): Детальная проработка всех 4 заданий говорения: чтение вслух, вопросы по объявлению, интервью и монологическое высказывание по фотографиям.
✍️ Письменная часть (Writing): Задания 37 (email) и 38 (высказывание по данным) со встроенным счётчиком слов и контролем лимита (100–140 / 200–250 слов).
📚 Лексика и Грамматика: Интерактивные карточки лексики с произношением, разбор типичных грамматических ловушек (depuis/pendant/pour, субъюнктив и др.) и тексты для чтения.
🌐 Двуязычность (RU/EN): Полная локализация интерфейса и инструкций. Идеально подходит для международных школ или студентов, изучающих русский язык.
⏱️ Экзаменационный таймер: Встроенный секундомер с пресетами:
Экзамен: 190 минут (формат письменной части ЕГЭ по иностранным языкам).
Тренировка: 60 минут.
🛡️ Anti-AI Approach: Задания составлены так, чтобы проверять реальное знание языка, а не просто переводить слова. Варианты ответов перемешиваются, правильные ответы открываются только после попытки студента.
🚀 Как использовать
Способ 1: Локальное использование (Рекомендуется)
Скачайте файл index.html из этого репозитория.
(Опционально) Положите рядом файлы audio-fr.mp3 и audio-fr-oral.mp3, если они у вас есть. Если нет — приложение само использует резервное аудио.
Откройте index.html двойным щелчком мыши в любом современном браузере (Chrome, Firefox, Edge, Safari).
Нажмите кнопку ▶ в правом верхнем углу, чтобы запустить таймер.
Переключайте язык кнопкой RU / EN.
